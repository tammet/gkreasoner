# Birds workload

## Case and query

A bird `b1` and a penguin `p1`; penguins are birds and do not fly; a bird
flies by default unless its failure to fly can be established. The measured
query is `flies(b1)`. The input also contains a recursive ancestor relation
over two father chains:

```prolog
anc(X,Y) :- father(X,Y).
anc(X,Y) :- anc(X,Z), anc(Z,Y).
```

The transitive closure has quadratically many ancestor pairs. The
derivation of `flies(b1)` does not use them. The workload records whether a
system evaluates the closure before answering the query.

## Input correspondence

For a requested even number `N`, `make_constants.py` generates two father
chains with exactly `N` named constants in total, with the same facts and
rules in each system's syntax. The committed [`generated/`](generated/)
inputs contain 1,000 constants; other sizes are generated on demand.

The GK clause for the default is:

```json
[["-bird","?:X"], ["flies","?:X"],
 ["$block",3,["$not",["flies","?:X"]]]]
```

The corresponding ASP rule is:

```prolog
flies(X) :- bird(X), not -flies(X).
```

The [clingo](https://potassco.org/clingo/) file tests the query by adding
the constraint `:- flies(b1).`; `UNSATISFIABLE` is therefore the successful
result, meaning that no counterexample stable model exists.
[DLV](https://dlv.demacs.unical.it/) runs in cautious-query mode. The
[I-DLV](https://github.com/DeMaCS-UNICAL/I-DLV) input uses `nonflies` as
the explicit exception predicate; in this program it has the same role as
the strong-negated `-flies` predicate in the other ASP files.
[s(CASP)](https://gitlab.software.imdea.org/ciao-lang/sCASP) and gk query
`flies(b1)` directly.

## Systems and versions

The measured implementations were gk 1.0.0, clingo 5.6.2, DLV (the
official x86-64 static release), I-DLV 1.1.6, and s(CASP) 1.1.4 on
[SWI-Prolog](https://www.swi-prolog.org/) 9.2.9. On the basic
bird/penguin input, gk, clingo, DLV, and s(CASP) all establish the
expected answer.

## Normalized results

Single runs on an Intel Core i7-10875H with 8 cores, 16 hardware threads,
and 30 GiB of memory. Wall time and maximum resident set size come from
`/usr/bin/time`.

| Constants | gk | clingo | DLV | I-DLV | s(CASP) |
|---:|---|---|---|---|---|
| 1,000 | `true`; 0.40 s; 176,724 KiB | `UNSATISFIABLE`; 10.34 s; 42,472 KiB | cautiously true; 27.80 s; 90,824 KiB | `flies(b1)`; `<0.01 s`; 5,668 KiB | 30 s limit; 716,468 KiB |
| 2,000 | `true`; 0.39 s; 194,040 KiB | `UNSATISFIABLE`; 99.95 s; 146,288 KiB | 180 s limit; 256,108 KiB | `flies(b1)`; `<0.01 s`; 6,180 KiB | 1 GiB stack limit after 27.55 s; 1,337,852 KiB |
| 100,000 | `true`; 5.83 s; 348,676 KiB | 30 s limit; 56,284 KiB | 30 s limit; 962,624 KiB | `flies(b1)`; 0.24 s; 52,172 KiB | 1 GiB stack limit after 19.70 s; 1,635,540 KiB |

`/usr/bin/time` printed `0.00` for the two smaller I-DLV runs; the table
records that as `<0.01 s` at the command's resolution. gk had search
limits of one second for the two smaller inputs and ten seconds for the
largest; all three runs returned an answer within their limits. The
100,000-constant clingo and DLV runs had 30-second external limits, the
2,000-constant DLV run a 180-second limit, and every s(CASP) run a
30-second limit; the two larger s(CASP) runs reached SWI-Prolog's default
stack limit first. Further protocol detail is in [`results.md`](results.md).

## Interpretation

clingo reported 0.00 seconds solving for both completed inputs; its
measured time was spent reading and grounding. DLV materializes the
closure before answering its cautious query. I-DLV's Magic Sets rewriting
restricts evaluation to the supplied query and does not materialize the
unused ancestor closure. gk proves the query directly and also does not
materialize the closure. s(CASP) avoids complete grounding, but this
left-recursive encoding leads it into deep recursive search.

## Function-symbol variant

The two rules

```prolog
bird(f(X)) :- bird(X).
penguin(f(X)) :- penguin(X).
```

generate `f(b1)`, `f(f(b1))`, and so on. For clingo and DLV, positive
recursion through `f` requires an infinite ground program; the recorded
runs on the committed variant inputs did not finish, and the s(CASP) run
on its recursive variant also did not finish. gk proves `flies(b1)`
directly from `bird(b1)` and the default clause without enumerating the
terms generated by the unrelated recursion.

## Reproduction

The generator requires [Python 3](https://www.python.org/). From the
repository root, generate a size and syntax:

```sh
python3 Examples/asp_comparison/make_constants.py 2000 --system gk \
  --output gbirds_2000.js
```

`--system` is one of `gk`, `clingo`, `dlv`, `idlv`, or `scasp`. Command
forms used for the measurements, with `clingo`, `dlv`, `idlv`, and `scasp`
standing for the installed executables:

```sh
/usr/bin/time -f 'WALL_SECONDS=%e MAX_RSS_KB=%M' \
  ./bin/gk gbirds_2000.js -seconds 1
/usr/bin/time -f 'WALL_SECONDS=%e MAX_RSS_KB=%M' \
  clingo clingo_birds_2000.lp --stats=2
/usr/bin/time -f 'WALL_SECONDS=%e MAX_RSS_KB=%M' \
  timeout 180s dlv -cautious dlv_birds_2000.dlv
/usr/bin/time -f 'WALL_SECONDS=%e MAX_RSS_KB=%M' \
  idlv --query --silent idlv_birds_2000.lp
/usr/bin/time -f 'WALL_SECONDS=%e MAX_RSS_KB=%M' \
  timeout 30s scasp -s 1 scasp_birds_2000.pl
```
